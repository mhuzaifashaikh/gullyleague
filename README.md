# Gully League Stats

i’m trying to make an app for my football games with my cousins called “gully league” it’s an app that will track top scorers, assisters and top goalkeeper wins 

it will have a seasonal standings page and weekly page for these stats from each game..

there will also be an admin mode which will record these metrics the admin mode will work as following 
- in admin mode there will be add players section which will be the players database
- there will be a “start game” button which will start recording for a game and will ask who all are playing today (from the players database) 
- once selected and started the screen will only show 3 big buttons “goal” “assist” “end game”
-once goal or assist is clicked it will pull up the players currently playing and ask to select (as in who just scored/assisted) and append the new games metrics accordingly
