

# Gully League - Your Football Tracking App

## Overview
A bold, sporty app to track your cousin football games with leaderboards for top scorers, assisters, and goalkeeper wins. All stats stored in the cloud so everyone can check them anytime.

---

## Pages & Features

### 1. Home / Dashboard
- League logo and "Gully League" branding
- Quick glance at current leaders (top scorer, top assister, best keeper)
- Navigation to view full standings
- "Enter Admin Mode" button (PIN protected)

### 2. Leaderboards Page
- **Tab: Season Stats** - Cumulative stats for the current season
- **Tab: This Week** - Stats from games played this week
- Each tab shows:
  - 🏆 Top Scorers ranking
  - 🎯 Top Assisters ranking  
  - 🧤 Top Goalkeeper Wins ranking
- Clean, sporty card design with player names and stats

### 3. Admin Mode (PIN Protected)

#### Player Management
- Add new players (name, optional photo)
- View all players in the database
- Edit or remove players

#### Start Game Flow
1. Press "Start Game" button
2. Select which players are playing today (multi-select from player list)
3. Assign a goalkeeper for each team (Team A & Team B)
4. Game starts with big action buttons

#### Live Game Recording
- Three large, easy-to-tap buttons:
  - ⚽ **GOAL** - Opens player selector for who scored
  - 👟 **ASSIST** - Opens player selector for who assisted
  - 🏁 **END GAME** - Finish recording and save
- Running tally of current game stats visible
- When ending: Select winning team (so keeper gets credited)

#### Season Management
- View current season info
- "End Season & Start New" button to archive and reset

---

## Visual Style
- **Bold & Sporty design** with vibrant colors (think grass green, dynamic orange accents)
- Dark headers with bright accent buttons
- Large, touch-friendly buttons for game recording
- Player cards with rankings and stats
- Mobile-first design (easy to use on the pitch)

---

## Backend (Cloud Database)
- Player profiles stored in cloud
- Game records with goals, assists, and keepers
- Season tracking for archival stats
- All data synced so everyone can view leaderboards
